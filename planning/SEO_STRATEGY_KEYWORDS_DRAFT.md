# GE Chemical 英文站 SEO 建站方案与关键词规划

状态：**DRAFT / 供业主评审**
日期：2026-10-02
范围：`gemasterbatch.com` 英文站；产品范围以现有资料和已确认的 W3/W4 方向为准。阿联酋、沙特为并列核心市场，越南为重要增长市场；“全球英语”是网站服务范围，不代表全球各国搜索需求相同。

## 1. 目标与定位

网站首先帮助大批量买家评估 GE 的黑色母粒供给、初筛型号，并进入型号匹配、试样或报价对话。主要买家是色母粒制造商的技术与采购链；贸易商／经销商为第二路径。自然搜索既是发现入口，也是已经通过销售或渠道接触 GE 的买家核验供应商的入口。首要 KPI 是合格黑色母粒询盘及后续销售进展，不以泛流量或词量代替商机。

这是 [SITE_BRIEF](SITE_BRIEF.md) 中业主已确认的战略，不把旧关键词研究中印度／美国的词量或填充母粒机会改写为本项目的优先级。

## 3. 首批信息架构与发布顺序

**第一批：可支撑黑色母粒成交判断的核心页面。** 首页、`/products`、`/products/black-masterbatch`、经核实的核心型号页、`/about`、`/manufacturing-quality`、`/documents`、`/rfq`、`/contact`。黑色产品族页应有：供给范围、适合初筛的型号维度、型号资料链接、真实制造证明、所需询盘信息、明确的下一步。型号页应列实际 TDS 对应的数据与条件，而非套用相同的营销文案。`TDS--PT-400.doc` 的公开型号按业主确认写 **PT-450P**。

**第二批：有条件的扩展。** 核实 DM2476G 当前供给与文件关系后考虑除湿产品族／型号页；对白色和彩色补齐可供范围与买家问题后，决定是否从 `/products` 拆出。优先研究包装薄膜中确有 GE 型号依据的独立问题。旧 FAQ 优先并入有责任的产品、文件与询盘页面。

**暂不按关键词批量建页。** 不做国家 × 应用 × 树脂矩阵；不因旧站有八个应用页和 34 个 FAQ 详情就全部复制。每个旧 URL 要结合当前 HTTP 状态、内容、GSC、入链和询盘价值决定保留、合并、重定向或退役。上述路径为 W4 候选；最终规范 URL 和迁移表尚未批准。

建议主导航：Products（突出 Black Masterbatch）、Manufacturing & Quality、Documents、About、Contact；持续可见的 RFQ 入口。产品族链接型号和文件，型号页回链产品族并引向相关证据及 RFQ；资讯文章只在能回答真实采购问题时发布，并链接对应商业页。

## 4. 页面内容和技术基线

- 一页一个主要买家任务。标题、H1、正文与内部链接对应同一个查询族，避免首页、产品目录、黑色产品族和多个型号页重复争 `black masterbatch supplier`。
- 用可核实的型号数据、工厂图片、实验室／生产说明和真实文件范围支持判断；公开主体仅用 **GE Chemical & Polymer Group Co., Ltd.**。公司规模为业主认可的公司自述，合规文件保持样品或型号范围。
- RFQ 表单收集买家角色、目的地、树脂、加工方式、终端制品、目标／问题、预计用量、所需文件与联系方式；具体字段以销售实际跟进能力定稿。保留可用的备用联系方法。
- WordPress 上线前核验 HTTPS、可抓取与索引设置、规范 URL、XML sitemap、移动端、图片尺寸和页面速度；接入 GSC 与 GA4。结构化数据仅标注页面真实可见的信息，不让标记替代产品证据。
- 改版前做完整旧 URL → 新 URL 去向表；逐个核对当前 HTTP、canonical、内部链接与 301 目标，避免将不相关旧页统一跳到首页。

## 5. 90 天执行与验证

| 阶段 | 工作 | 完成验证 |
|---|---|---|
| 0–2 周 | 核对现售 BK/PT/DM 型号、文件范围、联系与 RFQ 处理人；导出旧 URL、GSC/GA4 和重定向资料 | 每个公开产品声称有对应来源；核心旧 URL 有当前状态与去向；基线按阿联酋、沙特、越南及设备分别记录。 |
| 3–6 周 | 完成第一批页面的页面责任、内容和站内链接，优先黑色产品族与核心型号；在本地／预发布环境核验 | 目标查询族只有一个主答案页；型号参数与 TDS 一致；询盘提交与备用联系可实际送达。 |
| 7–10 周 | 受控发布并提交 sitemap；核验索引、跳转、canonical、移动端与表单 | 重点页可抓取、正确索引；旧 URL 到相关目标；GSC 无意外覆盖或 404 增长。发布按项目独立审批流程执行。 |
| 11–13 周 | 观察查询与询盘质量，决定白／彩／除湿和应用内容下一批 | 分市场比较 GSC 点击／展示／可见查询与 GA4 自然搜索会话、RFQ 事件及销售合格线索；两套指标分别报告。 |

GA4 关键事件如未完成采集，应标为 **deferred**，不能当作零。GSC 查询可能被匿名化或压制；报告时同时列可见查询合计与整体合计。没有实际询盘／订单来源记录时，不声称某关键词带来成交。

## 6. 当前数据缺口与改变方案的条件

1. 七个黑色 TDS 型号和 DM2476G 哪些现售，哪些是主要出口型号；PT-450P 是否可公开、各型号差异是什么。
2. 旧站完整 URL、GSC/GA4、入链与历史重定向；本轮公开站点页面打开失败，未完成实时页面审计。
3. 阿联酋、沙特与越南的真实询盘、成交、复购和赢失原因；这决定地名词、应用词及语言结构是否需要独立页面。
4. 白色和彩色的供给与技术资料，除湿的 GE 对外文件关系；这决定后续页面优先级。
5. 文档申请、样品、MOQ、交期、报价和 RFQ 的实际执行政策。
