# 第 2 课：色母粒的组成

- 课程编号：02
- 适合对象：零基础
- 更新日期：2026-08-04
- 核验状态：已核验

## 一句话定义

> **着色剂（colorant）**是赋予颜色的成分，包括颜料或染料。
>
> **颜料（pigment）**通常不溶于所加入的介质，而是以微小颗粒分散（较均匀地铺开）来产生颜色；**染料（dye）**通常能在适用介质中溶解来产生颜色。[SRC-007]
>
> **功能成分**是为了让材料具有某种特定作用而加入的成分；**助剂（additive）**是为加工（把原料做成塑料制品的过程）、分散、稳定（帮助材料在规定条件下保持预期状态）或特定功能加入的辅助成分。
>
> **载体（carrier）**是在色母粒里包住颜料或助剂，并把它们带入塑料的树脂等基材。

> 因此，色母粒可以用“载体＋着色剂或功能成分＋必要助剂”作为基础理解框架。

聚合物（polymer）是构成塑料主体的长链材料；树脂可以先理解为能受热加工成形的一类材料，基材是承载其他成分的基础材料。

SRC-007 支持颜料、染料与着色剂的上述基础区别；SRC-002 和 SRC-003 支持颜料或助剂在聚合物或树脂等载体中形成浓缩材料（较少材料中集中含有较多着色或功能成分）的基础关系。这些来源都不能用来推算某一产品的组成比例。[SRC-002][SRC-003][SRC-007] 这个框架只说明各类成分可能承担什么作用，不是任何产品的公开配方（各种成分及用量的组合）。某款色母粒实际含有哪些成分、各有多少，只能依据该产品对应的技术资料、样品验证和供应方确认。

## 通俗解释

可以把色母粒想成一次运输：载体像把货物带到目的地的运输工具，颜料、染料或功能成分像要送到塑料里的货物，必要助剂像为了让装载、运输或卸货更顺利而使用的辅助物品。色母粒加入基础树脂（构成最终塑料制品主体的主要塑料原料）并加工后，这些成分才进入制品。

这个比喻只能帮助理解“谁承载、谁提供颜色或功能、谁起辅助作用”。真实材料不是车辆和货物；比喻不能说明成分之间怎样作用，也不能用来推算成分种类、配方比例、添加比例（色母粒加入量与基础树脂或总混合料用量之间约定的关系）或最终性能。

## 为什么要学习这个主题

只看到色母粒的颜色，不能知道它的载体是什么、使用了哪类着色剂、是否有某种助剂，也不能知道它是否适合客户的树脂和加工条件。理解组成后，读者才能明白为什么选型（根据使用条件选择合适产品）不能只按“黑色”“蓝色”等颜色名称进行。

“分散”（dispersion）是让颜料或助剂较均匀地铺开在载体或塑料中的过程或状态。学完本课，读者应能分清四个概念：

- **载体**负责承载并帮助分散其他成分；
- **颜料**通常以微小颗粒分散来着色；
- **染料**通常在适用的材料环境中溶解后着色；这种材料环境在后文简称“介质”；
- **助剂**为加工、分散、稳定或特定功能提供辅助。

以上是基础理解，不能代替具体产品资料。

## 关键知识

### 1. 载体承载其他成分，但不等同于客户的全部基础树脂

载体是在色母粒里包住颜料或助剂，并把它们带入塑料的树脂等基材。它既提供承载环境，也帮助其他成分在母粒中分散。SRC-002 和 SRC-003 支持聚合物或树脂等载体与颜料、助剂形成浓缩材料这一基础关系。[SRC-002][SRC-003]

客户的基础树脂构成制品的主要塑料部分；载体只是色母粒中的组成部分。两者可能属于相同或不同的材料体系，不能仅凭名称或外观判断。相容性（compatibility）是两种材料在给定加工和使用条件下能否合适地配合；载体与客户树脂的相容性需要按具体产品和使用条件核对。

SRC-004 列出了 Avient Omnicolor 这一特定产品的适用聚合物范围，它只能说明该产品有明确的适用边界，不能证明其他色母粒具有相同范围。[SRC-004]

### 2. 颜料和染料都是着色剂，但着色方式不同

颜料通常是不在适用介质中溶解、而以微小颗粒分散来产生颜色的着色物。这里的“介质”可以先理解为着色物所在的材料环境。染料通常能在适用介质中溶解来产生颜色。Colour Index 引用的行业定义还指出，颜料通常保留颗粒或晶体结构，并以分散方式用于包括塑料在内的材料。[SRC-007]

“通常”很重要：有些着色物在不同应用过程中可能表现为染料或颜料，实际表现也会受到具体物质、载体、基础树脂和加工条件影响。颜料与染料不能因为颜色看起来接近就简单互换；选择哪一类，应依据具体产品资料、目标树脂、加工条件和最终用途确认。本课只提供基础区分，不判断任何具体牌号（具体产品型号）使用的是颜料还是染料。[SRC-007]

### 3. 助剂是辅助成分，不是统一清单

助剂是为了加工、分散、稳定或某种特定功能而加入的辅助成分。SRC-002 和 SRC-003 支持母粒可以包含助剂，并支持助剂可通过载体形成浓缩材料这一基础关系。[SRC-002][SRC-003]

不同产品的目的和设计不同，实际是否使用助剂、使用哪一类以及用量多少，都要看对应资料。看到“色母粒”这个名称，不能反推其中必然有某一种助剂。

### 4. 基础组成框架不等于具体配方

为了学习，可以先记住：

> 载体＋着色剂或功能成分＋必要助剂

斜线式理解也可以写成“载体＋着色剂/功能成分＋必要助剂”，其中斜线表示产品可能以着色、功能或二者的组合为目的，不表示每款产品包含完全相同的成分。

“必要助剂”表示只有在产品设计需要时才会加入相应辅助成分。这个框架不说明成分比例，也不能根据颗粒颜色、形状、产品名称或宣传名称猜测配方。

### 5. 组成选择要回到实际使用条件

至少要核对以下三类条件：

- **载体与客户树脂的相容性**：两者需要在实际条件下合适地配合，不能把一个产品的适用范围直接套给另一个产品。
- **加工温度**：processing temperature，指材料在实际加工过程中经历的温度条件。需要确认具体载体、着色剂和助剂是否适合该温度范围；本课不提供任何通用温度数值。
- **最终用途**：制品最后用在哪里、需要完成什么任务。用途不同，需要核对的材料、文件和验证项目也可能不同。

SRC-006 是 Avient 氟聚合物（含氟的一类特种塑料）着色浓缩物页面，明确说明其页面所覆盖的应用要求、加工条件和所需功能会影响产品选择。它只用于示范“选型要结合应用和加工条件”，不推广为全部树脂的适配规则。[SRC-006]

### 6. 实例证据不能跨出原来的范围

SRC-005 讨论的是 HDPE（高密度聚乙烯，一类塑料）压力管用黑色母粒。在该文章明确讨论的情境中，载体与基础树脂的熔体黏度差异会影响母粒混入；“熔体黏度”是塑料熔化后流动阻力的大小。这个实例说明载体匹配会影响加工与结果，但不能据此推断其他树脂、其他用途或其他产品的配方与性能。[SRC-005]

## 实际例子

假设客户只说：“我要生产黑色塑料收纳箱，请推荐黑色母粒。”颜色信息只说明了目标外观的一部分，还不足以推荐具体产品。

供应方至少还要确认：客户使用什么基础树脂；候选色母粒的载体是否与该树脂合适地配合；收纳箱采用什么加工方式；实际加工温度条件是什么；成品最终怎样使用；以及用什么样品或颜色标准确认“黑色”。确认候选产品时，还应查看对应技术资料，并按双方约定进行样品验证。

这个例子没有假定黑色来自哪一种具体着色剂，也没有猜测着色剂含量、配方或添加比例。即使两个产品都叫“黑色母粒”，它们的载体、组成和适用条件也可能需要分别核对。

## 与其他概念的关系

| 概念 | 它是什么 | 与色母粒组成的关系 |
|---|---|---|
| 载体 | 在色母粒里包住颜料或助剂，并把它们带入塑料的树脂等基材 | 承载并帮助分散其他成分；不等同于客户的全部基础树脂 |
| 颜料 | 通常不溶解、以微小颗粒分散的着色物 | 是着色剂的一类；具体能否使用要结合材料和条件确认 |
| 染料 | 通常能在适用介质中溶解的着色物 | 是着色剂的另一类；不能凭颜色与颜料简单互换 |
| 助剂 | 为加工、分散、稳定或特定功能加入的辅助成分 | 是否含有、种类和用量取决于具体产品资料 |
| 基础树脂 | 构成最终塑料制品主体的主要塑料原料 | 与色母粒一起加工；需要核对它与载体的相容性 |
| 分散 | 让颜料或助剂较均匀地铺开在载体或塑料中的过程或状态 | 是理解载体作用的重要概念，但不等于对每次加工结果作保证 |
| 加工温度 | 材料在实际加工过程中经历的温度条件 | 是核对载体、着色剂和助剂是否适用的条件之一 |

## 常见误区

1. **误区：只要颜色一样，色母粒就可以互换。** 不对。颜色相近没有说明载体、着色剂类型、助剂、相容性、加工条件和用途相同。
2. **误区：载体就是客户使用的全部基础树脂。** 不对。载体是色母粒中的承载材料；基础树脂是制品主体所用的主要塑料原料。
3. **误区：颜料和染料只是两个名字，可以随意替换。** 不对。二者通常具有不同的分散、溶解或应用方式，具体选择需要材料资料和应用验证。[SRC-007]
4. **误区：基础组成框架能用来计算配方。** 不对。框架只帮助认识成分类别，不提供比例，也不能代替具体产品文件。
5. **误区：某个多用途产品支持多种树脂，所以其他产品也一样。** 不对。SRC-004 只支持 Omnicolor 页面明确列出的产品范围。[SRC-004]

## 在产品选型中的意义

组成知识让选型从“看颜色”转向“核对材料和条件”。载体匹配是选型条件之一，但不是唯一条件；还要结合目标树脂、加工方式、加工温度、最终用途、目标颜色以及对应产品资料。

选型时不能从外观或产品名称反推内部组成，也不能用一份企业产品页证明另一款产品适用。SRC-004、SRC-005 和 SRC-006 分别只有产品或应用情境内的证据效力，不能跨范围形成通用配方、性能或适用性承诺。[SRC-004][SRC-005][SRC-006]

## 在外贸中的意义

外贸沟通中，供应商和客户至少要相互确认：

- 候选色母粒采用什么载体，载体信息来自哪份产品文件；
- 客户实际使用的目标树脂是什么；
- 最终制品做什么、在哪里使用；
- 采用什么加工方法，以及实际加工温度条件；
- 目标颜色如何对照；
- 需要哪些对应产品、批次、样品或用途的技术文件，以及用于判断是否符合适用要求的合规文件。

这些问题用于澄清和核对，不表示产品已经适用，也不构成性能、价格、交期、最小订购量或合规承诺。资料无法覆盖的问题，应继续向供应方或客户确认，而不是靠产品名称和经验猜测。

## 本课小结

- 色母粒可用“载体＋着色剂或功能成分＋必要助剂”作为基础理解框架，但这不是具体配方。
- 载体承载并帮助分散其他成分，不等同于客户的全部基础树脂。
- 颜料通常以微小颗粒分散；染料通常在适用介质中溶解，二者不能简单互换。
- 助剂为加工、分散、稳定或特定功能提供辅助，不同产品需要分别核对。
- 载体与客户树脂的相容性、加工温度和最终用途都会影响选择。
- 只知道目标颜色不足以推荐产品，还要确认树脂、载体、加工方法、用途和相关文件。
