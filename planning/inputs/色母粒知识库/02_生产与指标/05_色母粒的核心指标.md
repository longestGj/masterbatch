# 第 5 课：色母粒的核心指标

- 课程编号：05
- 适合对象：零基础
- 更新日期：2026-08-04
- 核验状态：已核验

## 一句话定义

> 色母粒的核心指标，是用来回答“颜色像不像、混得匀不匀、加工时会怎样、受热或见光后会不会变化、含水情况和批次是否可比较”等问题的检查项目；每个结果都要连同测试方法、测试条件和判定依据一起看。

这里的**指标**是要观察或比较的项目，例如色差或熔体质量流动速率；**测试方法**是怎样测这个项目的约定做法；**测试条件**是测量时不能省略的环境、样品和仪器设置，例如试样树脂、添加比例、温度、负荷、光源或观察角度。条件一变，同名指标的结果可能不能直接横向比较。

本课建立“该问什么、该看什么文件”的入门框架。ISO（国际标准化组织）的公开摘要支持：熔体质量流动速率和熔体体积流动速率在指定温度和负荷下测定，主要用于质量控制，不能自动等同于实际加工表现；CIE 1976 L*a*b* 色空间和色差计算属于标准化颜色测量术语框架。[SRC-008][SRC-009] 本课不引用未取得的标准正文，也不提供任何产品的通用合格阈值。

## 通俗解释

把指标想成给产品“对照同一张试卷”：题目是什么、怎样答、在什么条件下答，都要一致，分数才有比较意义。只看到一个数字，通常还不知道它是在什么树脂、什么添加比例、什么仪器条件下得到的；因此不能急着说“更好”或“合格”。

还要把下面四件事分开：

| 要分开的内容 | 白话意思 | 不能混为一谈的原因 |
|---|---|---|
| 指标 | 要回答的问题，例如“与对照颜色差多少”。 | 项目名称本身不说明怎样测。 |
| 测试方法 | 测量、制样或比较采用的约定步骤。 | 同名指标可能使用不同方法。 |
| 测试条件 | 测试时的样品、树脂、添加比例、仪器和环境等上下文。 | 条件不同，读数的含义和可比性可能不同。 |
| 典型值、规格值与验收值 | **典型值**是资料中用于描述代表性表现的数值；**规格值**是产品文件明确规定的要求值或范围；**验收值**是买卖双方或相关文件用于判定能否接收某批产品的依据。 | “有一个典型值”不等于它就是规格或客户验收界限；规格值能否用于验收，仍须看当前文件和双方确认。 |

## 为什么要学习这个主题

客户说“色差要小”“流动性要稳定”时，外贸人员不宜只回复“可以”。更有用的做法是把话题落到可确认的信息：这是哪款产品、哪种基础树脂、按多少添加比例、用什么试样和方法、在什么条件下测、资料中的数值属于典型值还是规格值，以及客户准备怎样验收。

指标不是一张脱离产品的成绩单。它不能单独证明色母粒适用于任何树脂、设备或最终制品，也不能单独作出法规、批次稳定性或最终性能承诺。需要时还应查看对应批次的检测记录、样品和双方确认的验收要求（OPEN-003、OPEN-004）。

## 指标总览：每一类在回答什么问题

| 类别 | 常见项目 | 它想帮助回答什么问题 | 本课的阅读边界 |
|---|---|---|---|
| 颜色表现 | 着色力、色差、L*a*b* | 颜色强弱和与对照样的差异怎样描述？ | 需要确认样板树脂、添加比例、制样和测色条件。 |
| 分散与洁净度 | 分散性、过滤性能 | 着色剂或助剂是否较均匀地铺开？与过滤相关的表现要如何核查？ | 不能凭肉眼现象或项目名称断定根因或合格与否。 |
| 加工行为 | 熔体质量流动速率（MFR）、熔体体积流动速率（MVR） | 在指定测试条件下，熔融材料的流动结果怎样？ | MFR/MVR 主要用于质量控制，不能直接等同于实际加工表现。[SRC-008] |
| 热与光稳定性 | 耐热性、耐光性 | 在约定受热或受光条件后，颜色或外观变化是否需要继续比较？ | 具体受热、受光条件和判定方法尚待确认。 |
| 含水和批次一致性 | 含水率、批次一致性 | 样品中水分结果怎样？不同批次能否在同一规则下比较？ | 必须确认取样、测试方法、条件、记录和验收要求。 |

### 1. 颜色表现：先问“拿什么颜色来比”

**着色力**是颜色材料在已确认的比较体系中呈现颜色强弱的相对表现。它回答的不是“这款产品绝对有多好”，而是“相对于指定对照物，在指定树脂、添加比例和制样条件下，颜色强弱怎样”。没有对照物和条件，单独说“着色力高”信息不完整。

**色差**是试样与对照样之间颜色差异的描述。ISO/CIE 11664-4:2019 的公开摘要说明，该标准规定 CIE 1976 L*a*b* 色空间坐标的计算方法，包括明度、彩度和色相的相关量，并包含以欧氏距离表示感知色差大小的计算方法。[SRC-009] 可访问的摘要没有直接给出 L*、a*、b* 各轴的白话方向含义；本课也未取得任何具体的光源、观察者、仪器、样板或容差要求，因此不作这些扩展。

阅读颜色资料时，至少问清：

- 对照的是客户样、色卡、留样还是哪一批标准样？
- 试样使用什么基础树脂、什么添加比例和什么制样方式？
- 色差是以哪一种测量体系表达，测试条件和仪器设置是什么？
- 数值是典型值、产品规格中的要求，还是双方已确认的验收值？

### 2. 分散与洁净度：看“是否均匀”和“需核查什么”

**分散性**是颜料或助剂在载体或塑料中是否较均匀地铺开的表现。它与第 4 课的“分散”有关，但“看上去有条纹、颗粒或黑点”不等于已经证明分散性不合格；原料、设备、加工条件、试样和观察方法都可能需要核查（OPEN-004）。

**过滤性能**在本课中是一个便于提问的统称：它指与过滤步骤或过滤相关检查有关的表现。具体要测什么、采用什么装置或怎样判定，必须以某个产品的当前文件、双方约定或已确认方法为准。本课不把“过滤性能”当作已有公开标准的统一项目，也不写筛网、压差、残留物或任何通用界限。

面对分散或洁净度问题，可以先记录产品和批号、基础树脂、添加比例、加工方式、问题样和对照样、出现位置及照片或实物；之后再由对应资料、检测或试验确认，而不是从一个现象直接给出唯一原因。

### 3. 加工行为：MFR/MVR 的条件不能省略

**熔体质量流动速率**（MFR，melt mass-flow rate）是热塑性材料在规定测试中按质量表示的流动结果；**熔体体积流动速率**（MVR，melt volume-flow rate）是按体积表示的流动结果。ISO 1133-1:2022 的公开摘要说明，两项数据在指定温度和负荷条件下测定，主要用于质量控制；其**剪切速率**（熔体在流道内相邻层相对滑动时速度变化的快慢）低于正常加工，数据未必总能对应加工行为。[SRC-008]

因此，看到 MFR 或 MVR 时应同时确认：

- 是 MFR 还是 MVR，单位写的是什么？
- 测试温度和负荷是什么，样品状态和测试方法是什么？
- 资料标的是典型值，还是明确写出的规格值；客户的验收值又是什么？
- 要比较的是同一类材料、同一条件下的批次，还是不同树脂、不同产品？

不能只因两个资料页都写了 MFR 或 MVR 就直接排序，也不能把一个结果说成“机台一定好加工”的承诺。

### 4. 热与光稳定性：先固定暴露条件再谈变化

**耐热性**是材料在约定受热条件后保持预期表现的能力；**耐光性**是材料在约定受光条件后保持预期表现的能力。对于着色母粒，客户可能关心颜色、外观或其他指定项目在比较前后有没有变化。

这两个名称并不自带统一测试条件。实际沟通需要确认受热或受光的方式、持续时间、试样树脂、添加比例、比较项目、方法及判定依据。本课不以公开来源外推任何温度、时间、光源或“耐几级”的通用要求；此类条件和验收界限仍属 OPEN-003。

### 5. 含水和批次一致性：让比较有可追溯的上下文

**含水率**是样品中水分的测试结果或表达方式。它至少要连同取样位置、样品状态、测试方法、测试条件、单位及判定依据阅读；脱离这些信息，不能把不同产品或不同批次的数值直接比较。

**批次一致性**是同类产品在不同生产批次间，是否在已确认的比较范围内保持一致的目标。它不是一个只看单项数字就能自动证明的结论。比较批次时，应确认产品版本、批号、原料或样品状态、测试方法和条件、测试记录，以及双方认可的规格或验收依据。

## TDS 怎么读：把资料页变成可核对的问题

**TDS**（technical data sheet，技术数据表）是随产品提供的技术信息文件。它可以帮助定位产品所列的指标和测试信息，但不能替代对具体产品、批次和客户用途的确认。

按下面顺序阅读会更稳妥：

1. 先确认 TDS 的产品名称、版本、发布日期和适用范围；不要把另一产品或旧版本的数据套用过来。
2. 找到指标名称和单位，再找测试方法与测试条件；若只写数字而未写清条件，向供应方追问。
3. 分清资料写的是典型值、规格值还是其他描述。典型值用于说明代表性表现；规格值是产品文件明确规定的要求值或范围；规格值是否可用于验收，仍须看当前文件和双方确认。
4. 把客户要求与 TDS 一项项对应：客户的基础树脂、添加比例、加工方式、样板和验收方法是否相同？不同就不能直接认定可比。
5. 对需要验收的项目，另行确认当前批次的检测记录、允差或验收值、抽样规则和争议处理方式；这些不是由本课或一份典型值自动给出的。

## 实际例子

客户询问一款用于 PP（聚丙烯）收纳盒的蓝色色母粒，并说“希望颜色稳定、流动性一致”。外贸人员不能据此承诺色差或加工结果，而可以先整理问题：客户用哪一种 PP、添加比例是多少、是否有对照色样、试样怎样制备、色差要用什么测量体系、MFR 或 MVR 要在什么温度和负荷条件下比较、需要的是 TDS 中的典型值还是双方确认的验收值。

如果客户随后给出一个色差数字，却未给光源、观察者、样板、树脂和制样方式，这个数字只能说明还缺少比较条件。若客户给出一项 MFR，也应继续核对其单位、温度、负荷和资料性质；不能据此推断任何设备上都会有相同加工表现。[SRC-008][SRC-009]

这个例子没有给出配方、添加比例、色差容差、MFR/MVR 数值、温度、负荷或承诺。实际结论需要当前产品文件、样品和双方确认的测试及验收条件。

## 与其他概念的关系

| 概念 | 它解决什么问题 | 与核心指标的关系 |
|---|---|---|
| 基础树脂 | 最终制品主体用什么主要塑料 | 会影响试样和测试结果的可比性，必须写清。 |
| 添加比例 | 色母粒加入基础树脂或混合料的约定关系 | 颜色、分散及其他结果的解释可能需要知道这一条件。 |
| 分散 | 颜料或助剂是否较均匀地铺开 | 是分散性关注的基础概念，但现象不等于唯一根因。 |
| 检测 | 按约定方法查看某个项目 | 要同时保留方法、条件、单位和判定依据。 |
| 批次 | 同一生产记录范围的一批产品 | 让检测记录、留样和后续比较有可追溯对象。 |

## 常见误区

1. **误区：色差数字越小，就能直接说产品一定合格。** 不对。还要确认测量体系、样板、树脂、添加比例、仪器条件和客户验收依据（OPEN-003）。
2. **误区：TDS 上的典型值就是每批产品的验收承诺。** 不对。典型值、规格值和验收值性质不同，必须查看当前文件并向供应方和客户确认。
3. **误区：MFR/MVR 可以直接预测所有实际加工表现。** 不对。公开摘要明确其主要用于质量控制，且其测试剪切速率低于正常加工，数据未必总能对应加工行为。[SRC-008]
4. **误区：看见条纹、黑点或颗粒，就能认定分散性不合格。** 不对。需要同时核查原料、设备、加工、样品和测试/观察条件，不能只凭现象归因（OPEN-004）。
5. **误区：耐热、耐光、含水和过滤性能都有一套可直接套用的数值。** 不对。具体方法、条件和验收要求需要按产品、用途和双方文件确认（OPEN-003）。

## 在产品选型中的意义

指标帮助把“看起来合适”变成可核对的问题，但不代替选型结论。选择候选产品时，仍要结合基础树脂、加工方式、最终制品、客户目标、当前 TDS、样品和必要试验。产品资料中即使列有颜色、流动、热稳定性或其他项目，也要确认它们的测试条件是否与客户场景相近。

例如，客户把 MFR 看作重点时，可以把它列入待比对项；但是否适合客户的机台、制品和加工条件，不能从一个 MFR 数字单独推导。涉及具体树脂和加工方式的适配，还需要后续课程中的资料、样品或供应方确认（OPEN-005）。

## 在外贸中的意义

客户问指标，往往是在问“你怎样证明这款产品与我的要求有关”。外贸人员可以先把信息收齐：

- 候选产品、TDS 版本和要比较的具体批次是什么？
- 客户关心的是颜色、分散、洁净度、加工、耐热/耐光、含水还是批次一致性？
- 每个项目的测试方法、单位、测试条件和对照样是什么？
- 数值是典型值、规格值，还是客户已经确认的验收值？
- 是否需要样品、当前批次检测记录或在客户条件下的试验来确认？

这些问题用于澄清技术信息，不构成对颜色、加工性、批次一致性、法规、最终制品性能、价格或交期的承诺。涉及具体标准正文、容差和验收时，只能索取并核对对应产品、版本和双方文件（OPEN-003）。

## 本课小结

- 指标、测试方法、测试条件以及典型值、规格值和验收值必须分别阅读。
- 颜色、分散与洁净度、加工行为、热与光稳定性、含水和批次一致性，是帮助初学者组织问题的五类框架；不代表所有产品都有同一套项目或方法。
- MFR/MVR 要连同温度、负荷、单位和方法阅读，且不能自动等同于实际加工表现。[SRC-008]
- L*a*b* 和色差的公开标准信息只支持颜色测量术语框架；具体仪器、样板、容差和客户验收必须另行确认。[SRC-009]
- 阅读 TDS 时，要核对产品版本、方法、条件、单位和数值性质；需要验收时还要确认当前批次和双方约定。

## 自测问题

1. 指标、测试方法和测试条件分别是什么？为什么不能把它们混在一起？
2. 为什么典型值不自动等于规格值或客户验收值？
3. 阅读色差资料时，至少要补充哪些样板、树脂或测量信息？
4. MFR/MVR 为什么必须连同温度和负荷阅读，且不能直接等同于加工表现？
5. 客户询问“耐热和耐光怎样”时，哪些条件还需要确认？
6. 遇到条纹或黑点时，为什么不能立刻判定分散性不合格？

## 仍待确认事项

- **OPEN-003：** 具体产品的测试方法、条件、标准正文、仪器设置、规格/验收界限和客户要求尚未确认。本课仅引用 SRC-008、SRC-009 已公开的摘要与元数据范围，不给出通用阈值。
- **OPEN-004：** 色差、黑点、条纹、分散不良或过滤相关现象的具体根因和“合格/不合格”条件不能由通用资料或远程描述确定。本课只使用“需要核查”和“另行确认”的表述。
- **OPEN-005：** MFR/MVR 或其他单项结果与某一树脂、设备、加工方式和最终制品的实际适配关系，不能从本课直接推导；需要当前 TDS、样品或机台试验及供应方确认。
