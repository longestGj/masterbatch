- 更新日期：2026-08-04

## 知识库用途

本知识库用于帮助零基础读者建立色母粒的基础认识，并为生产指标、应用选型、质量问题、询盘外贸和资料核对提供统一入口。课程所讲的色母粒，是供塑料加工使用、常见为颗粒的浓缩材料，使用时与构成制品主体的基础塑料混合。

## 零基础读者说明

可从第一门课程开始，按顺序阅读。遇到不理解的专业词，先查阅[色母粒术语表](术语表/色母粒术语表.md)；术语表中的白话解释优先服务于没有化学、塑料加工或外贸背景的读者。

## 内容边界

当前 12 课覆盖产品基础、生产流程与核心指标、应用与选型、常见质量问题，以及询盘与外贸确认流程。课程用于建立入门框架和核对顺序，不猜测具体配方、性能、价格、交期、MOQ（最小订购量）或合规结论，也不把教学示例改写成具体产品承诺。

## 如何使用来源和待确认标记

[来源索引](参考来源/来源索引.md)记录来源能支持的具体结论、适用范围、证据强度和查阅日期。TDS（技术数据表）、SDS（安全数据表）、检测报告和企业官网只支持其明确覆盖的公司、牌号、批次或样品，不可泛化。

[待确认事项清单](待确认事项/待确认事项清单.md)用于登记尚未有充分证据的问题。稳定通用知识、资料支持的具体事实和待确认内容必须明确区分；标准、法规、市场、合规和可能变化的技术事实需要核验当前权威来源，并记录链接与查阅日期。
