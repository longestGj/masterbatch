# Limited PRD: Black / White / Color Masterbatch RFQ Content

Status: Limited PRD Draft  
Date: 2026-07-05  
Not a full website PRD. Not a development task. Not for Cursor or Minimax execution.

## 1. Scope

This limited PRD only covers three RFQ-oriented content pages:

- Black masterbatch buyer/RFQ page
- White masterbatch buyer/RFQ page
- Color masterbatch RFQ guide

This limited PRD does not include:

- Full website PRD
- Market pages
- Filler page
- Desiccant page
- Application pages
- Cursor task
- Minimax task
- Code implementation
- Final route list

## 2. Business Goal

The goal of these three pages is not to display fixed product parameters. The goal is to help overseas B2B buyers submit more complete RFQs so the supplier can evaluate product fit, document needs, application requirements, and quotation feasibility.

Target buyers include:

- Packaging film factories
- Plastic bag factories
- Injection molding companies
- Recycled plastic processors
- Plastic raw material distributors
- Masterbatch importers

Each page should work as a buyer qualification and RFQ preparation page: buyer problem first, required inputs second, supplier evidence caveats always visible.

## 3. Evidence Boundary

### Black Masterbatch Evidence Boundary

Available evidence:

- Current files include TDS examples for BK020, BK025, BK030, BK035, BK040, PT-300, and PT-450P.
- Current files include one GE CHEMICAL black masterbatch SDS/MSDS.
- Current files include one GE CHEMICAL RoHS report for a black masterbatch sample.
- File entities include GE CHEMICAL & POLYMER GROUP CO., LTD, BINZHOU LEACHY NEW MATERIAL CO., LTD, and Wudi Longda public product-map references.

Public-safe claims:

- Current documents include several black masterbatch TDS examples.
- Some current black masterbatch TDS examples mention film blowing, injection molding, and re-granulating applications.
- Current documents can support buyer discussion around blackness, dispersion, carrier resin, carbon black requirement, application fit, and document review.

Claims not allowed:

- All black masterbatch grades are RoHS compliant.
- All black masterbatch grades are FDA compliant or food grade.
- All grades have fixed carbon black percentage, fixed MFI, fixed dosage, fixed carrier resin, fixed filler content, or fixed application suitability.
- Product is pipe-grade, UV grade, potable-water grade, ISO/ASTM compliant, or suitable for regulated uses without grade-specific proof.

Required caveats:

- Technical data must be confirmed by exact grade and supplier file.
- RoHS/FDA/food-contact claims must not be generalized from one report or TDS note.
- Entity mapping must be confirmed before public launch.
- COA availability is not confirmed in current files.

### White Masterbatch Evidence Boundary

Available evidence:

- Public product map indicates white masterbatch category and model families.
- Current files include one GE CHEMICAL FDA 21 CFR 177.1520 extractables report for White Masterbatch / White Plastic Chips, Grade MB Blanco PE.
- No white masterbatch TDS, COA, or SDS/MSDS was found in the current folder.

Public-safe claims:

- One current GE CHEMICAL file shows a tested white masterbatch sample, Grade MB Blanco PE, under the specified FDA extractables test.
- White masterbatch can be discussed as an RFQ topic for whiteness, opacity, TiO2 requirement, carrier resin, application, and document needs.
- Public copy may say document availability must be confirmed by grade.

Claims not allowed:

- All white masterbatch is food grade.
- All white masterbatch is FDA compliant.
- All white masterbatch is suitable for food-contact packaging.
- Fixed TiO2 content, guaranteed opacity, fixed whiteness, fixed dosage, fixed carrier resin, or full grade availability.

Required caveats:

- If the FDA report is mentioned, state that it applies only to the tested sample/grade, not the full white masterbatch product line.
- White TDS, COA, and SDS/MSDS are still required before publishing technical parameters.
- Any TiO2, opacity, and compliance discussion must be framed as RFQ questions, not product promises.

### Color Masterbatch Evidence Boundary

Available evidence:

- Public product map lists warm color, cool color, other color, and LD/LDA/LDG series examples.
- Company profile mentions color masterbatch generally.
- No color masterbatch TDS, COA, SDS/MSDS, or compliance file was found in the current folder.

Public-safe claims:

- Supplier public research indicates color masterbatch category and model-family signals.
- The page can ask buyers for resin type, color reference, application, processing method, tolerance target, sample needs, and document requirements.
- The page can position color masterbatch as an RFQ preparation workflow rather than a technical product specification page.

Claims not allowed:

- Exact Delta E tolerance.
- Pantone/RAL matching guarantee.
- Guaranteed sample lead time.
- Fixed MOQ.
- Batch consistency guarantee.
- Food-contact, RoHS, FDA, or other compliance claims.
- Specific shade availability without supplier confirmation.

Required caveats:

- Color matching, samples, MOQ, documents, and grade availability must be confirmed after RFQ review.
- The page should not publish fixed formulas, fixed pigments, or fixed sample rules.
- Any color reference language must be buyer-input oriented.

## 8. Content Style Rules

Page copy must follow these rules:

- Professional B2B export tone.
- Conservative evidence-based claims.
- Buyer problem first.
- RFQ checklist driven.
- No exaggerated factory claims.
- No unsupported compliance claims.
- No fixed MOQ, sample, or lead-time promises.
- No full-series certification claims.
- No direct copying from competitors.
- Technical data should be framed as grade-specific and document-specific.
- If documents are mentioned, explain that availability and applicability depend on exact grade and supplier confirmation.

## 9. PRD Acceptance Criteria

This limited PRD is acceptable only if:

- Scope is limited to three pages.
- No route finalization is included.
- No development instruction is included.
- All claims respect supplier evidence.
- RFQ questions are complete.
- Meta/H1/search intent are defined.
- Not allowed claims are clearly listed.
- Filler, desiccant, market pages, application pages, and full website PRD are excluded.
- The document remains a limited PRD draft, not a build ticket.
