## Buyer Problem Section

## What color masterbatch buyers usually need to clarify

Color masterbatch inquiries often require more context than a color name. The team needs to understand resin, processing method, final product, color reference type and target expectations before reviewing the inquiry.

Common inquiry situations include:

- An injection molding buyer needs a custom color for molded parts.
- A packaging or plastic product buyer needs color consistency discussion.
- A distributor needs color reference and document review for a customer.
- A buyer needs to compare a current grade or previous supplier grade.

This page is an RFQ guide. It is not a technical product specification page.

## What Buyer Should Prepare

## Information to prepare before requesting color masterbatch

To help the team review your inquiry, please prepare:

- Base resin, such as PE, PP, ABS, PET, PVC or another resin.
- Processing method, such as injection molding, film blowing, extrusion or another process.
- Final product or application.
- Color Reference Type: Physical sample, Pantone code, RAL code, Photo, Existing product, Previous supplier grade, Customer standard or Not sure.
- Color reference details, if available.
- Target color or function.
- Tolerance expectation, if your customer has one.
- Product grade / model, if known.
- Current grade or supplier, if any.
- Trial quantity and estimated monthly quantity.
- Required technical or compliance-related documents.

## Application Context

## Application context for color masterbatch RFQs

Color masterbatch inquiries may involve injection molded parts, packaging products, plastic bags, household plastic products or distributor sourcing. The application helps the team review resin compatibility and processing context.

Color matching and sample discussion are case by case after RFQ review. This page must not promise exact Delta E, Pantone matching, RAL matching, sample timing, fixed commercial terms or batch consistency.

## RFQ Form Explanation

## What to include in your RFQ

Please include the following information in your RFQ form:

| RFQ Item | What to provide |
|---|---|
| Product interest | Color masterbatch |
| Base resin | PE, PP, ABS, PET, PVC or other |
| Processing method | Injection molding, film blowing, extrusion or other |
| Color Reference Type | Physical sample, Pantone code, RAL code, Photo, Existing product, Previous supplier grade, Customer standard or Not sure |
| Color reference details | Code, photo note, sample description, existing product details or customer standard |
| Application | Injection part, packaging, bag, household product, distributor inquiry or other |
| Target expectation | Buyer expectation only, not a fixed promise |
| Product grade / model | Current grade, target replacement model or known GE grade, if available |
| Quantity | Trial quantity and monthly quantity |
| Documents requested | TDS, SDS/MSDS, COA, RoHS-related, FDA-related, food-contact-related or other files |

The more complete the RFQ is, the easier it is for the team to review color feasibility, sample discussion needs and document scope.
