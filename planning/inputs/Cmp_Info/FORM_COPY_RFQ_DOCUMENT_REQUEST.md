# Form Copy Draft: RFQ And Document Request

Status: Form Copy Draft  
Public entity: GE CHEMICAL & POLYMER GROUP CO., LTD

## 1. Form Title

Request a Quote or Technical Document Review

## 2. Form Intro

Please submit your product interest, application, country / region, resin, processing method, product grade / model if known, and required documents. GE CHEMICAL & POLYMER GROUP CO., LTD will review the product grade, application and document scope, then reply by email.

Technical documents are provided after RFQ review when suitable. The website does not provide public file access.

## 5. Required Field Rules

Always required:

- Name
- Company
- Email
- Country / Region
- Product Interest
- Application

Required when requesting documents:

- Documents Requested
- Document Purpose

Recommended for RFQ review:

- Base Resin
- Processing Method
- Product Grade / Model, if known
- Trial Quantity
- Monthly Quantity

Recommended for color masterbatch inquiries:

- Target Color / Function
- Color Reference Type
- Color reference details in Message, if available

## 11. No-download Notice

Technical documents are not available through public or automatic file access. Please request TDS, SDS/MSDS, COA or compliance-related documents by form. Our team will review your request and reply by email.

Do not use these messages:

- Your document is ready.
- Get the file now.
- Certificate sent automatically.
- Available for immediate access.
- Public document access.

## 12. Manual Review Notice

Every RFQ and document request is reviewed manually. GE CHEMICAL & POLYMER GROUP CO., LTD reviews the product interest, product grade / model if known, application, country / region, document type and document purpose before replying.

Not every product has every document. Compliance-related documents, if available, apply only to specific tested grades or samples.
