# Buyer copy review

Use this method to review what a prospective buyer will read and infer from a page. The caller supplies the candidate, approved page direction, factual boundaries, URL/search ownership, and any action or destination decisions. This method does not grant authority to edit or approve content.

## Read the candidate as a buyer

Read the actual buyer-visible content before the author's rationale or self-check. Continue from the first visible element through the last even after finding a serious defect. For a content skeleton, judge the page task, section order, essential candidate wording and action path without demanding finished paragraphs. For full copy, include every heading, paragraph, list, table label, qualifier, CTA, link label, form instruction and applicable state message.

Determine what decision this page helps the buyer make, where its page-specific answer appears, and what the buyer can do next. Walk a relevant incomplete-information case if the journey allows it. Identify wording that is unclear, unnatural or repetitive enough to change understanding; do not turn equally clear stylistic alternatives into required fixes.

## Check meaning against approved inputs

For each material claim, compare the named entity, product or service, value, unit, condition, relationship, qualifier, geography and date with the approved source as applicable. A source URL alone does not support a stronger claim. If third-party material is cited, check what that source actually says and whether the link label describes its real destination. Mark essential unsupported or uncheckable claims as decisions needed; do not supply an invented fact.

Trace each meaningful request or promise as `buyer → action → destination or receiver → expected result`. Check buttons, imperatives, form help and post-action copy. Challenge any promise to download, receive, submit, qualify or obtain something when the approved destination or outcome does not support it. Compare internal links with approved page responsibilities. Ensure SEO Title, Meta and H1 express the same supported meaning as the visible page; a keyword target is not permission to strengthen a claim.

## Report and recheck

Finish the full scan, then rank the material issues. For each required finding, give its location, likely buyer interpretation and impact, the source or decision it conflicts with, a concrete change needed, and an acceptance condition. Group repeated instances of one problem but name every affected location. Separate required fixes, unresolved decisions and optional suggestions. A review with no real defect needs no invented finding or element-by-element PASS list.

Identify the highest-risk action expectation, the least clear material wording and any missing page-specific answer only where these help the recipient understand the findings. Report source or behavior limits honestly. Return findings in the caller's existing review channel or artifact; this skill does not require a new report file, manifest or status system.

For re-review, read the revised candidate and verify each open finding against its acceptance condition and nearby copy. If facts, source meaning, section structure, CTA behavior or the buyer path changed, reread the entire candidate. The author's claim that an issue is fixed is not verification.
