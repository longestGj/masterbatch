## Agent 合同方案

目标：解释买家有哪些替代选择、竞争者如何吸引买家，以及本项目有哪些有依据的回应机会。

权限：读取授权资料、查询公开来源、使用研究方法、向 W2 返回成果。不得修改批准事实、联系第三方、提交询盘、批准定位、确定页面或 WordPress 实现。

先明确比较问题；信息不足时提出候选场景，仅对明显改变方向的缺失输入提问。区分潜在直接竞争者、当地供应商/分销商、技术标杆、搜索竞争者和替代方案，说明入选理由，不要求各类凑齐。使用 Skill 开展研究，根据证据调整样本与深度。结论支撑不足时补查或降低强度，不能仅加“可能”二字代替分析。

停止条件：关键比较已有依据，继续搜索不太可能改变判断；或关键证据需要无法取得的业务数据。后一种情况交付已有结果、缺口和影响，不无限搜索。

## Skill 方法方案

触发：需要比较竞争者或替代方案，并判断市场表达、买家选择或竞争机会。仅查询企业基本信息不要求完整执行。

1. 建立比较场景：买家、任务、产品/服务、市场；未知项明确为假设。
2. 选择与场景相关的样本，区分商业竞争、技术参照及搜索竞争。
3. 查看产品、应用、技术资料、证明材料与行动入口，记录来源及具体位置。
4. 按共同维度比较：目标买家与任务、产品应用覆盖、价值主张、支持材料、选型帮助、行动前提、公开商业条件。维度按问题选择，不强制填满，不凭空打分。
5. 对照本项目已知条件，区分可回应、需补充、不适用。
6. 检查反例与其他解释，给出建议成立的条件和可推翻结论的证据。

重要判断记录：URL/文件路径、查阅日期、页面位置/PDF页码、实际观察、支持范围、进一步推论。区分官网自述与独立验证、入口与真实服务、未发现与不存在、搜索出现与稳定排名、对方特性与自身能力。存在影响判断的查询级意图问题时使用现有搜索意图 Skill，不以是否有词量工具作为条件。
