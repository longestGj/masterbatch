## 成果审查

做得好的部分：六项均有覆盖；区分事实、自述、推论和假设；保留 PT-450P 与样品范围；未照搬历史词量或竞争空白；未替业主批准市场或启动 W3。

需要补齐的部分：

1. **市场比较较浅。** 塑料大盘和当地供应商存在，不能支持 GE 市场选择。按相同维度比较候选市场的相关产品需求线索、供给格局、GE 已知匹配条件和关键缺口；信息不足时给条件性建议或明确无法排序的理由，不编造评分。
2. **买家仍是通用角色。** 加工厂、贸易商等来自教学框架，尚未说明各角色的具体采购触发、比较问题、所需证据、下一步动作及 GE 当前可回应的内容。可形成有依据的候选场景，不必等访谈齐全，也不能把假设写成访谈结论。
3. **竞争者比较维度不齐。** 现稿分别观察 TDS、产品种类、语言等，不能直接横向取舍。选择与当前问题相关的技术标杆、潜在商业对手或搜索参照，说明选择理由，按共同维度比较价值表达、选型信息、证明材料及行动入口；未查到就明确空缺。
4. **机会缺少比较与反证。** “牌号选型”“应用问题”“跨境资料配合”方向可保留，但应说明分别适用于谁、依据是什么、GE 哪些输入可支持、什么证据会推翻它。W2提供比较输入，W3形成定位建议，业主作决定。
5. **交接问题范围偏宽。** 市场、语言、CTA、商业条件、文件获取、旧 URL 同时交给业主，仍将分析负担外推。优先提出真正改变当前比较的少数问题；旧 URL 保留等后续决策留给对应阶段。

## 拟议的 Agent / Skill 分工

**W2 Agent：负责研究任务的组织与交付边界。** 保留六项范围和只读角色；增加问题选择、方法调用、候选比较与完成标准。成果仍由主任务整合为一份 `planning/W2_RESEARCH.md`。不决定最终市场、不批准定位、不安排页面 URL、不干预 WordPress。

**拟新增一个 `market-buyer-research` Skill：负责可复用的研究方法。** 不拆成六个 Skill，不固化色母粒公司和国家。

建议方法：

1. 从 W1 与用户目标提取本轮要支持的决策，区分已知、可复用、需要补查的缺口。
2. 按缺口选证据与代表样本，记录为何选择；没有真实销售数据时使用可检验的候选场景。
3. 把来源观察转成买家任务和比较维度；来源能支持什么与研究者推论分开。
4. 比较候选路径，说明支持证据、反例、GE/当前项目匹配条件及缺失条件。
5. 对影响取舍的搜索意图问题调用现有 Skill；仅列主题时保留候选身份，不强制搜索。
6. 输出建议研究结论、适用条件、W3 可承接的选择依据及少数关键问题。新增证据不再改变取舍时停止；未解决的关键问题注明影响范围。

**现有 `search-intent-evidence-analysis`：只在必要处调整适用范围。** 当前开头强调 page decision，W2 尚处在站点研究阶段。可扩成网站/页面研究决策，继续保留实际查询、条件、代表页面及反例要求；不把定性研究错误地绑定到搜索量或 SEO 最终定案。

## 迭代验证与通过条件

先由业主确认上述分工，再修改 Agent 和 Skill。采用本轮已观察到的缺口作为基线，安排有限的对照试跑：

- 无真实询盘：能否产出有来源的买家假设和验证条件，而不是编造画像或停工？
- 旧报告声称竞争空白：能否查反例并限定结论，而不是照抄或无限研究？
- 市场未定：能否按共同维度提供条件性比较，保留业主决定权？
- 只有搜索主题与真正存在意图分歧：能否分别选择不调用和调用搜索 Skill？
- 输入目录错误：主任务能否回到明确的项目目录，不另建工作树或沿用旧项目指令？

之后让 W2 在主项目按新方法补当前稿，只补影响决策的缺口。复核是否更有取舍价值、来源可追溯、未扩大批准含义，是否减少反复提问与无关研究。结构校验与一次人工阅读不等于行为测试通过；未经试跑不宣称新方法已验证。

完成标准：六项研究各有支持的判断或清楚的证据缺口；重要候选可以比较；建议与批准分离；搜索结论不超出样本；W3能据此形成策略提案。无需把每一个未知都消除，也不以篇幅、链接数量或文档数量判断完成。
